# React Rating App

A React application built to practice reusable UI components, component architecture and scalable project structure.

The project focuses on applying React fundamentals in a structured application and separating UI components, business logic and reusable functionality.

## ✨ Features

* Interactive rating interface
* Reusable React components
* Component-based UI architecture
* Separation of presentation and application logic
* Reusable patterns for working with component state
* Structured and maintainable project organization

## 🛠️ Technologies

* React
* JavaScript
* CSS
* Vite
* Git / GitHub

## 📁 Project Structure

The project is organized around reusable React components and separates different application responsibilities.

```text
src/
├── components/
├── pages/
├── hooks/
├── services/
└── ...
```

The structure is designed to make components easier to reuse, test and extend as the application grows.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/nndio/react-rating-app.git
```

### 2. Navigate to the project directory

```bash
cd react-rating-app
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local development URL provided by Vite.
